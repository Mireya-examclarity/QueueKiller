 QueueKiller - Skip The Line, Live Your Life

> **Real Problem:** We waste 20-30 minutes daily standing in physical queues at canteen, xerox shop, clinic, fees counter.
> **Solution:** A digital token system. Take token, wait anywhere, get notified when it's your turn.

Built for **Frictionless Challenge (NASA Stardance)** - 2+ hrs in VS Code with Python + Streamlit only.

---

 What it Does

QueueKiller replaces physical lines with a smart digital queue board.

- **Take Token:** Enter name, select place (Canteen, Xerox, Clinic etc), get Q001, Q002...
- **Live Board:** See who is NOW SERVING with pulse animation
- **Wait Prediction:** Calculates ~2.5 min per person ahead
- **Chai Break Feature:** If you have 6+ mins, it tells you "Go grab chai, we hold your spot"
- **Admin Controls:** Shop owner can call next, clear queue, add demo data
Components:
- **Language:** Python
- **Framework:** Streamlit (no Flask, no HTML needed)
- **State:** `st.session_state` for live queue
- **Styling:** Custom CSS + Google Fonts (Space Grotesk + Outfit)
- **Deployment:** Streamlit Cloud

 How to Run

1. Clone / download folder
2. Install: `pip install streamlit`
3. Run: `streamlit run app.py`
4. Open: `http://localhost:8501`

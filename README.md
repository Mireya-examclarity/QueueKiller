# QueueKiller - Skip the line. Live your life.

### The Real Problem

Everyday, we waste 20-30 mins standing in queues itself - canteen, xerox shop, clinic, fees office. In these days heat, you cannot leave the line or you lose your spot. If you go to use the loo , your turn is gone.
QueueKiller converts physical queue into digital. Take a token Q001 from your phone, look at the live board, know how many are ahead you and how long you need to wait till your turn. Wait anywhere - shop will call you on your turn.
This not a new to-do app. This is solving a real, physical, daily problem for 1000s of students.

### Features

-  Digital Token system - Get Q001, Q002 from your phone instantly

-  Live Board - Now Serving (pulsing animation), know who's being served NOW

-  Wait Time Prediction - 2 mins per person, know exact waiting time

-  Multiple Locations - Canteen, Xerox, Clinic, Fees Office, Bus Counter

-  Mood Tags - Chill, Normal, Urgent

-  Owner Controls - Call Next, Clear All, Add Demo data

-  Smart Tips - If wait time >>>> 6 mins - "Go grab tea, we'll hold spot"

-  Cool UI - Glassmorphism cards, gradients, Space Grotesk font

### Tech 

- Backend: Python Flask

- Frontend: HTML, CSS (Glassmorphism), JS

- Hosting: Hack Club Nest (non-sleeping, always live) + GitHub Pages (backup)

- No database needed - in-memory queue (perfect for small shops)

- Zero cost, zero hardware.

### How It Works

1. Student enters name and selects place (e.g., College Canteen)

2. Gets token Q001 instantly

3. Live board shows: NOW SERVING Q001, Q002 is next (3 mins)

4. Student waits anywhere, watches live board

5. Shop owner clicks "Call Next" - next token gets notified
